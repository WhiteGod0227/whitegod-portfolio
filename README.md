## ✨ Features

- **🖤 Aesthetic Black-Bluish Midnight Obsidian Theme**: Deep obsidian `#030712` canvas with radiant electric cyan (`#00f0ff`) and sapphire (`#3b82f6`) neon glows.
- **⚔️ Interactive Katana Smash Opening**: Custom Web Audio API sound synthesis, dual screen-slice animation, and sparkling particle burst.
- **✨ Smooth Cursor Aura Trail**: Lag-smoothed electric cyan and sapphire mist trail tracking the cursor.
- **📜 The Arsenal (Three Breath Disciplines)**:
  - 🌊 **Breath of Code**: Full-Stack Development (React, Node.js, Express, MongoDB, REST APIs)
  - 🔥 **Breath of Frames**: Video Editing (Premiere Pro, After Effects, CapCut, Motion Graphics)
  - 🎨 **Breath of Form**: Graphic Design & UI/UX (Figma, Photoshop, Canva, Branding)
- **🎬 9:16 Video Reels Showcase**: Interactive video reels with hover animations and links.
- **🔮 Grimoire Core Inspector Modal**: Live backend health checker, server uptime monitor, and real-time scroll database viewer.
- **📬 Self-Healing Contact API**: Automatic failover between local and live cloud endpoints with persistent storage and email notification support.

## 🛠️ Tech Stack

### **Frontend**
- HTML5 & Modern Semantic Elements
- CSS3 (Custom Design System, Glassmorphism, CSS Variables, Responsive Grids)
- Vanilla JavaScript ES6+ (HTML5 Canvas, Web Audio API, IntersectionObserver)

### **Backend & Storage**
- Node.js & Express.js
- MongoDB Atlas (with automatic local persistent JSON storage fallback)
- Helmet & Express Rate Limiting
- CORS security

### **Deployment**
- **Frontend & Serverless API**: Vercel Edge Global CDN
- **Continuous Service**: Render

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/WhiteGod0227/whitegod-portfolio.git
cd whitegod-portfolio
```

### 2. Install dependencies
```bash
npm install
npm --prefix server install
```

### 3. Run locally
```bash
# Start backend server with frontend static hosting
npm start
```

Open `http://localhost:5000` in your browser.
